# Spécification du rapport Power BI

## Page 1 : Mix énergétique
- Cartes : production totale, part renouvelable, CO2 moyen
- Aires empilées : production par source dans le temps
- Segments : date, source

## Page 2 : Consommation et météo
- Nuage de points : température vs consommation
- Courbe : consommation et température dans le temps
- Segment : ville

## Page 3 : Qualité et fraîcheur
- Table : derniers résultats de `ops_quality_results`
- Carte : dernière donnée ingérée
- Courbe : lignes rejetées par jour

## Règles de design
Palette sobre, titres explicites, pas plus de 6 visuels par page, infobulles utiles, thème cohérent.
